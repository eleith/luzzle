# Agents.md for @luzzle/web

Instructions for agents working on the `@luzzle/web` package (Web Explorer).

## Scope

The Web Explorer is the official viewer and content management system (CMS) for
Luzzle archives. It allows users to browse their content and, when authenticated,
edit pieces directly via a protected interface.

## Architecture

SvelteKit application.

- **Config:** Managed by `@luzzle/web.utils` via `config.yaml`. Controls theme,
  database location, auth, storage, and piece mapping.
- **Data Source:**
  - **Read:** Reads from the SQLite database generated by `@luzzle/web.tools`.
  - **Write:** Interacts with the filesystem or WebDAV via `@luzzle/core`
    Storage abstraction.
- **Rendering:** Server-Side Rendering (SSR) via `@sveltejs/adapter-node`.
- **Auth:** `Auth.js` integration with OIDC providers.

## Key Concepts

- **Docker Deployment:** Users build custom images using
  `examples/Dockerfile.custom` to bundle content.
- **Editor Namespace:** All editing routes live under `/editor` and are
  protected by authentication.
- **Piece Generation:** Uses AI (Gemini) to generate metadata from content.
- **Database:** Superset of the core database. `@luzzle/web.tools` adds tables
  for web aggregation and full-text search.

## Development

- **Dev Server:** `npm run dev`
- **Build:** `npm run build`
- **Check:** `npm run check`
