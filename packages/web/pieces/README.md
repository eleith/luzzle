# @luzzle/web.pieces 🧩

Internal shared package that handles web-specific helper logic and mappings for
Luzzle pieces.

## Purpose 🧠

This package exposes:

- Utilities to map schemas to UI components.
- Helpers to map general piece fields to web-friendly attributes (dates, cover
images, summaries).
- Type definitions and parsers used when rendering lists or grid views in
SvelteKit.

It is not published to npm.
